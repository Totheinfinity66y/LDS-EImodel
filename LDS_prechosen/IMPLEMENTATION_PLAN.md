# 分层 response 状态模型执行计划

## 目标与范围

逐项交付导师要求：A 分层约束；B 当前路线与文献路线的证据对照；C 独立可运行模型及验证。需求源为本目录《导师要求.md》。现有 `lds_decompressor` 保持原样；新代码只依赖 NumPy，放在 `LDS_prechosen`，不导入旧模型。

## 交付物与验收

1. `REQUIREMENTS_AND_ROUTES.md`：任务、表征、信息流、通路机制、动力学和科学解释六层约束；对照旧模型真实调用和本地工作稿 P0033、P0055–P0069；区分导师规范、文稿观察和建模选择。
2. `model.py`：R1/R2/R3/R4 分别 1/2/4/4 个六维 response 块。D 在 R1→R2 使用并清除；S 在 R2→R3 使用并清除；R3→R4 只读 response。正向阈值符合驱动默认关门，不使用抑制其他路径的 winner 门控。
3. `tests/test_model.py`：24 条件、重启、码删除、通路干预、无内容/无控制、混合 response 传播、数值步长、输入合法性和几何证据。
4. `evaluate.py`：从实际末态计算序列、各组合的中心化二维位置子空间及 principal angles；输出 JSON、CSV、NPZ、几何图与失败控制。几何计数不得直接输出配置中的块数。

## 执行与环境

已核查声明依赖及已有 analysis 环境：Python 3.12.12 / NumPy 2.3.5 / Matplotlib 3.10.7，CPU。显式调用解释器并临时补齐 Conda DLL PATH，不安装依赖。完成独立测试和旧模型回归后核对会话文件、Git 根与差异，按项目规则发起一次提交提案。

## 证据边界

固定环移、分块嵌入、阈值门和外部秩时钟均为预设。几何匹配验证实现满足约束，不等于神经数据拟合、学习得到的结构或生物因果机制。现有工作稿是否就是导师指称版本尚未确认；无法提供的数据和统计量明确标缺，不补造。实现不处理感知推断、block 奖励学习、真实细胞类型、噪声稳定吸引子和自主节拍。
