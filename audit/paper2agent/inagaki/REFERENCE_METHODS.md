# Inagaki 2019 原始方法契约

论文与公开作者代码均已获取。详见 INPUT_CONTRACT.json 与 FIGURE_CONTRACT.json。主图5/6来自多试次、多session的ALM胞外放电记录；主图2–4的膜电位不是主图5/6的输入。ED1/9为简化动力学模型，作者仓库仅覆盖这些模型及部分分析。

CD是选择性均值差，不是PCA。实验平滑100ms、步长10ms，最后600ms拟合；模型代码最后400ms拟合。固定延迟必须保持fit/test分离；随机延迟以非2秒fit、2秒test。模型代码未使用实验的交叉验证，不可混称。

末端分布和负phase-line斜率是原文支持点吸引子的证据；对LDS的全状态残差、Jacobian、Euler谱是额外数学诊断，不是原作者所有实验都做过的检验。不同外部驱动条件下的固定点不能合并为同一自治系统的多稳态。

来源内部差异：Methods说汇总median、图注说mean；原始模型代码采用mean及跨trial SD。复现必须明确采用哪一种。原文中心差分分母2对应每10ms步长；要标每秒必须再除0.01秒。

原始数据为Figshare doi:10.25378/janelia.7489253；尚未下载或核验原生文件schema，当前契约是从Methods推导的规范输入，不伪称原文件shape。
