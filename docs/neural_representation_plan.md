# 神经群体表征与动力学分析执行契约

目标：审计三个位置编码的正式实现与原始数据；开发并执行全群体、招募、记忆交接、子空间、表征几何、独立动力学实验和十组图；完成数学测试、视觉检查、中文报告、工程文档和提交提案。

模型、task、simulation、baseline 配置与历史归档保持原样。位置和规则标签仅用于离线分组或独立评价。固定随机种子 7、11、19；不安装包，不训练，不向远端推送。

## 交付顺序与验收

1. 数据审计与接口：核验当前模型源码 SHA256 与正式 v2 归档、24 条件、全部神经元、事件和 E/I 映射；生成 DATA_AUDIT，已有完整轨迹优先复用。
2. 活动与交接：全网络热图、条件矩阵、结构/功能支持、描述性因子分解、反馈消融与记忆/Response 信息可分辨性。阈值和窗口固定并保存。
3. 几何：全条件全网络统一 PCA、阶段/分支 SVD、角度与交叉 VAF、支持折叠对照、六位置 RDM/MDS、置换对照、明确划分的解码。退化相关性记 NA。
4. 动力学：独立状态副本，恒定驱动条件，完整状态残差、Euler Jacobian 谱、初态/扰动扫描、身份保留、恢复曲线及投影向量场的平面外分量。
5. 图与报告：三编码 Figure 1–9、Figure 10 对照，300 dpi PNG、SVG/PDF、原始数值、figure manifest、METHODS/RESULTS/SUMMARY 和具体文献 panel；逐图视觉核验。
6. 集成：自动化数学/数据/导出测试及原有边界测试，核对保护文件哈希、缓存身份和 Git 范围，发起本会话全部改动的提交提案。

## 分工和风险

主对话负责统一数据接口、审计、图生成、证据集成与文档。三个子对话分别拥有离线数学分析、独立动力学实验、文献证据文件，不并行编辑相同文件。

各编码均为相同 132 维内部网络；输入维数 6/1/2 不等于神经维数。分支结构预定义，角度必须与结构基线比较。六条件中心化 rank≤5 是样本上限。确定性条件不提供统计重复；噪声试次需要记录实际电流剂量。输入/神经几何和动力学稳定性分别判断，不将六离散位置称为连续环吸引子。

正式输出目录为 artifacts/neural_representation_v2，引用 handcrafted_ei/artifacts/v2/run 的只读数据。当前既有 PPTX 修改不属于本任务。
