# 逐页 AI 配图提示与幻灯片版式｜V2

## 统一视觉规范

- 画幅：横版 16:9；暖白／象牙白底，交大红作强调色，深灰作为正文色，少量灰绿辅助。
- 风格：简约、大气的科学期刊编辑插画；线条克制、留白充分、构图准确；不模仿任何期刊的具体版式。
- 版面：大标题＋单一核心图＋一条结论或公式。图片负责解释机制，中文、编号、公式和数据在幻灯片中用原生文字呈现。
- 图片共通约束：无可读文字、无数字、无 logo、无水印、无图表轴或结果数值；避免 AI 拼写错误。图片中红色适量点题，避免满版红色。
- 图的证据等级：概念插画只是解释机制的辅助图；只有项目归档的验证图、指标和复算记录表示当前模型结果。

## 逐页版式与生图提示

### 01｜封面：规则如何变成连续行动

版式：左侧约 40% 留白放标题和副标题；右侧约 60% 放六点环形路线图，不另加边框。页脚只留项目名。

提示词：横版 16:9，暖白纸面背景，右侧主体为六个等距圆形位置围成的环，三段朱红细箭头连接一条四阶段路径，少量深灰线路表现未激活位置，带轻微墨线质感，留白充足，极简科学期刊编辑插画；左侧 40% 保持干净留白供标题叠放；不含文字、数字、坐标、logo、水印。

### 02｜任务：六个位置与三次移动

版式：左侧放环形位置图，右侧放输入 `(L,D,S)` 和一个任务例子；页底写 `0 → 1 → 3 → 4`。所有数字在 PPT 中标注。

提示词：暖白背景、极简二维科学插画，一个由六个等距空心节点构成的圆环，朱红色路径按顺时针突出三段移动，路径经过四个节点，两个非相邻步长用清楚但克制的箭头表现，灰色展示其他未选路径；构图留白、节点规则、无数字文字和图例，适合 16:9 幻灯片的左侧 55% 图像区。

### 03｜问题框架：保持、选择、继承、读出

版式：五步横向信号流置于中央，左到右依次为输入、内部保持、门控选择、响应继承、位置读出；下方一句科学问题。

提示词：横版科学编辑插画，在暖白背景中以五组简化的神经群体符号表现信息流：短暂外部信号、持续的内部活动、被门控的分支、沿单一路径接力的响应、共同读出端；用朱红强调一个当前活跃分支，浅灰表现其他路径，精细线稿与轻微柔和颗粒质感，五组从左向右排列且不含任何文字或箭头标签，适合幻灯片中央。

### 04｜网络：E/I 率动力学与四阶段群体

版式：主图画 `R1 → R2 → R3 → R4 → Y`，侧边标出 `M_D`、`M_S`；下方放 104 状态和简化动力学方程。网络示意图的文字标签在 PPT 中编辑。

提示词：暖白背景的高水平神经科学机制插画，以四组由小圆点构成的响应神经群体沿左到右排列，方向分支逐步增加、然后在特定路径上接续；上下各有小型控制群体汇入前两次转换，末端汇入一个共同读出群；红色只突出被选中的群体，其他群以浅灰表示；克制精确的二维线描，不出现连线交叉和可读标签、不生成文字或数字，适合 16:9 幻灯片右侧图像区。

### 05｜门控：抑制抑制者，释放目标通路

版式：中心放四节点通路示意；下方放精确连接式 `M(E) → I_release ⊣ I_gate ⊣ E_target`，右上角配短语“规则控制通路；位置活动携带内容”。

提示词：科学期刊风格二维机制插画，暖白纸面背景，清晰展示从左侧源神经元到右侧目标神经元的一条水平兴奋通路，中间有一个常态抑制门，另一个位于上方的释放神经元通过抑制该门而打开通路；红色标出解除抑制的环节，深灰表示默认被压制的门，细线和简洁符号表达作用方向；空间关系明确、无文字无标签无数字、适合幻灯片横向主图。

### 06｜状态继承：已形成的分支继续推进

版式：中央画分支树，红色只追踪一个 trial 的活跃路径；下方放 `R1→R2（D）`、`R2→R3（S）`、`R3→R4（沿分支固定连接）`，以及 readout-first 时间线。

提示词：暖白背景的极简神经计算分支图，左边一个起始活动群体分出两个方向，中段每个方向再分出步长路线，右段沿已选中的一条具体分支继续一步；朱红只高亮同一条连续的被选路径，非选路线用浅灰细线淡化，节点大小统一、连线清楚；不含数字、文字或复杂背景，适合幻灯片横向中央图。

### 07｜验证：完整序列与真实活动轨迹

版式：左侧展示项目真实 `validation.png`（约 65% 宽），右侧放 `24/24`、四阶段 `100%`、`16/16` 测试和 `39 实验 / 936 trial` 复算；底注区分 trial 与独立样本。

配图：使用原始文件 `v1_validation_trajectories.png`，不经 AI 重绘，不改动图中的数据。旁边可加朱红细线指向读出轨迹。

### 08｜因果干预：在不同时间切断，影响不同阶段

版式：四阶段时间线为主图。下方用 A–D 四个短行表示操控点、阶段准确率、完整序列数；若放随机 lesion 对照，明确标注 seed=7/11/19，避免暗示普适统计结论。

提示词：暖白科学期刊风格的因果干预概念图，横向四阶段神经响应路线，四个小型红色切断标记分别出现在早期方向门、方向状态形成后、步长门、最终分支形成后；用浅灰虚影表示被阻断的下游活动，用红色标出干预点，结构简洁、布局规整、没有字母、数字或结果图表，适合幻灯片上半区。

### 09｜意义与边界：机制原型回答什么

版式：左侧列“支持：该固定机制可完成所定义任务”；右侧列“未证明：大脑采用此结构／吸引子／普适鲁棒性”；中间用一张证据边界示意图连接。避免胜负式红绿分栏。

提示词：暖白背景的科学证据边界插画，一条从简化电路到可测序列结果的红色路径止于一个明确的边界线，边界外以淡灰轮廓展示未验证的更复杂大脑网络，不画结论对勾叉号；表达“机制原型证据有范围”，高留白、细线条、克制构图，不含文字数字和 logo。

### 10｜后续：从适用范围走向必要机制

版式：三个递进主题横向展开：持续扰动／更长保持 → 必要结构／自主时序 → 新任务版本；下方一句优先级结论。

提示词：横版科学期刊风格路线图插画，暖白底，三个由左到右递进的简洁研究场景：对既有活动轨迹施加小扰动并观察恢复、逐步简化网络结构以定位必要连接、由网络内部信号触发下一阶段；朱红细线作为连续路径，灰色作为未探索区域，不含文字数字或 UI 面板，适合横向幻灯片中部。
