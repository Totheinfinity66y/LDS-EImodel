# v2机制替换与资料适用范围

本记录保存迁移事实；当前独立完整定义以[architecture.md](../architecture.md)为准。

| 被替换的规则/实现 | 当前规范 |
| --- | --- |
| 强制I_release⊣I_gate及禁止直接激活 | 必须M→E_gate→Response，记录E_gate率及必要性干预 |
| stop condition要求I→I中间层 | 禁止通过重新引入旧路由绕过直接激活判据 |
| L接口固定六维one-hot | 原始位置维度6/1/2，连续非负映射到六位置刺激 |
| memory全程高活动 | 门控前保持、Response形成后显式I反馈终止 |
| release/gate边故障注入 | memory→E_gate及E_gate→Response，A/B/C/D时机含义保留 |
| 104维硬编码复算 | 按schema核验v1的104维与v2的132维、labels/Y/groups一致 |
| M0–M5历史通过 | 新P0–P7独立判据，历史仅保留来源 |
| 保持或PCA聚类作为充分证据 | 分离自由/受迫、残差/谱/扰动/有限盆，不预设吸引子 |

原有独立Git仓库、提交提案、用户确认、禁止自动推送、依赖预检、红绿测试、源指纹、全率日志、信息隔离及Dale规则保持。evaluation只能在独立副本做扰动，不能影响正常trial。

docs中的20261025讲解、旧图和PPTX均为v1历史材料；文献阅读资料为外部背景。它们不用于描述当前主模型。保留用户已有未提交PPTX，不静默改写其内容。

## 验证期间诊断

- 首次完整31测试之前，吸引子测试把0.1 RMS恢复预设为断言，实际发现反例。正式检测幅度与阈值保留不变；单元测试验证已知小扰动和无递归衰减，研究结果允许跳转或不恢复。
- 实验接口审查发现recurrence lesion掩码混入60条前馈边。先记录红测试，再将掩码限制为对角自连接，恢复后31测试通过。首轮实验在到达该消融之前中断，保存在pilot_interrupted，不能当完整receipt。
- tonic与全recurrence精确匹配随机池可能退化为目标本身；events记录池规模。这些随机对照不支持额外的靶点特异性结论。
- 声明NumPy≥2.0以匹配记忆AUC的trapezoid接口；本机已验证2.3.5，未安装或修改环境。
