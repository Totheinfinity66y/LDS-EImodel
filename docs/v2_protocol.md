# E/I 解压缩实验契约

目标：在固定任务与信息边界下实现直接兴奋门控、Response 驱动的规则记忆终止，以及三种外部位置编码的对照。

允许输入：编码后的 L/D/S、无内容阶段电流。禁止输入：目标、下一位置、试次标签驱动的拓扑选择、读出驱动的状态回写。全部 24 条件为机制穷举，不是学习或泛化评测。

实验范围是外部编码变化、相同六位置 Response 网络。one-hot、相位和二维圆坐标经连续非负调谐映射产生位置电流；后两者产生宽调谐电流，禁止先离散解码为 one-hot。比较编码空间和电流空间的距离，不能声称改变了内部神经元维度。

P0 → P1 → P2 → P3 → P4 → P5 → P6 → P7。机制改造前保存源码与测试状态；新判据必须留下失败证据。每阶段见根目录 todo.md；最终保存全部 trial rates、独立任务真值、事件、配置、源码哈希、环境和复算结果。

否证：任何编码未达到 24/24、提前路由、交接前记忆丢失、交接后不衰减、切反馈仍同样衰减、无源仍产生位置、符号或信息泄漏，均不得报告机制通过。吸引子有无都允许；检测须对独立副本进行，关闭 sample 与全部 clock，并明确保留 tonic 背景。所有失败如实归档。


复现输出使用新的空目录；源码、配置、环境、活动与独立target分别归档。代码提交遵循根目录AGENTS.md。
