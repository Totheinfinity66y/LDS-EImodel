# 工作记忆压缩与解压缩项目汇报逐页提纲草稿

**用途：**面向没有项目背景的同学，说明研究问题、当前证据、机制假说与未来工作。建议 10 页、约 12–15 分钟。视觉暂定暖白底、交大红强调、简约科学期刊风格；图中不生成文字，公式和标注由幻灯片原生文本添加。

## 本次叙事的科学边界

项目总目标是解释工作记忆中序列信息如何被压缩、保持并按需解压缩，以及这种计算方式如何在神经资源、精度与干扰之间权衡。团队申请书提到，前期非人灵长类研究建立了序列压缩范式，并观察到前额叶皮层的压缩编码。仓库当前可直接复核的工程进展，则是一个固定连接、不训练的 E/I 解压缩原型：它从已给定的 `L/D/S` 开始，不负责发现压缩规则或拟合真实神经数据。

“延迟期—响应期重叠调谐”是神经数据层面的观察；“去抑制回路因果性地将同一群重叠神经元路由到不同子空间”是机制解释，需要与观察证据分开讲。当前 `handcrafted_ei` v1 的分支响应群是固定设计的，并不能证明真实大脑中的重叠神经元或其子空间路由机制。

## 1｜工作记忆如何把序列装下，又按需展开？

**本页要点：**本项目追问序列信息在神经活动中的压缩与恢复过程。

**屏幕文字：**工作记忆的压缩与解压缩｜从神经活动到计算机制

**配图：**暂留空位，等整套视觉主线确认后再定封面图。封面不先预设神经元、脑或数据流哪一种意象最合适。

**讲述：**我们关注的不是单独“记住了什么”，而是序列如何变成较紧凑的内部表示、如何在延迟中保持，以及需要时怎样依次恢复。

## 2｜为什么要研究压缩？

**本页要点：**容量受限时，分组或结构化编码可能降低记忆负担，但可能牺牲项目精度。

**屏幕文字：**有限资源｜紧凑表征｜精度与容量的权衡

**配图：**按用户选择，参考 Nassar 等（2018）《Chunking as a rational strategy for lossy data compression in visual working memory》的 Figure 2（二进制编码模型）。它用于解释“容量限制如何促使项目被分组编码”，只作为视觉类比；该模型研究视觉工作记忆，不是本项目序列任务的数据或结果。最终采用原图时在页脚/讲者备注标注来源；若不适合放原图，则按其概念另画，不混称为本项目证据。

**讲述：**压缩不是删除序列，而是以更少的有效资源保持对任务有用的信息。压缩是否有利，要看节省的资源是否超过精度损失与项目间干扰。

## 3｜序列压缩与解压缩是什么？

**本页要点：**长序列可用少数规则性 primitive 表示；解压缩则按顺序逐步生成位置。

**屏幕文字：**序列 → `L/D/S` 规则 → 逐项读出

**公式（标为当前原型任务例子）：**

`R₁ = L; R₂ = L + D; R₃ = L + D + D·S; R₄ = L + 2D + D·S (mod 6)`

**配图：**六位置环上示例 `L=0, D=+1, S=2`，按次序读出 `0 → 1 → 3 → 4`；同时显示 `L` 是起点、`D` 是方向、`S` 是步长。注明这是当前解压缩原型的简化可检验任务，不代表真实神经系统只用这三个变量。

**讲述：**先让听众看懂一个具体例子，再讲它为什么能把信息流拆成可检验的神经阶段。目标位置由评价器计算；模型接收的是 primitive 输入，不接收答案序列。

**屏幕文字：**行为范式与神经数据已建立｜编码、保持与恢复之间的动力学仍待解释

## 5｜重叠神经元与子空间：共享和分离如何共存？

**本页要点：**神经资源既可能跨任务阶段或序列长度复用，也需要在同一序列的不同位置间保持可分性。

**屏幕文字：**部分共享 → 资源复用与泛化；部分分离 → 降低序列内干扰

**配图：**用同一批神经元在不同任务阶段/序列长度的调谐图表示“部分重叠”；再用状态空间中方向不同但不强行正交的子空间表示“既复用又区分”。重叠部分只占示意群体的一部分，不能画成所有神经元全部共享。

**讲述：**相关序列工作记忆研究报告了共享调谐资源与相对分离的 rank 子空间并存：跨序列长度共享可支持泛化，同一序列内区分不同 rank 有助于减少干扰。重叠神经元是操作性定义下的群体，不等同于一个已识别的专门细胞类型。不同研究中“overlap”的定义（跨延迟/响应期，或跨 rank/序列长度）需要分别标注，不能混为一个结果。

## 6｜两种候选计算机制

**本页要点：**需要解释为何既有部分神经资源复用，又能按当前 primitive 进入正确表征通路。

**候选机制 A｜专属群体、固定子空间：**每个序列位置或 rank 主要由自己的神经群体编码。优点是表征区分清楚、干扰较少；代价是资源随序列复杂度增长，复用和泛化能力可能较弱。

**候选机制 B｜重叠群体、动态子空间路由：**部分神经元跨阶段/长度复用；`L/D/S` 与阶段信号改变当前有效通路，把活动送入需要的子空间。优点是复用有限资源；风险是子空间干扰，因而需要选择性路由。

**配图：**使用[修订版机制比较海报](project_brief_assets_20261025/mechanism_candidates_compare_draft_v2.png)。版式参照序列工作记忆论文中“群体分配/子空间结构”图与去抑制回路论文中的“细胞连接 motif”图：上方展示分离与共享两端，中间突出文献支持的混合几何（序列内多数位置表征相对分离、部分神经元跨位置重叠并改变调谐；不同序列长度间同 rank 可共享调谐），下方以虚线框单列候选去抑制路由机制。实线区域表示文献报告的表征现象，虚线区域表示尚待检验的机制假说；整图为概念示意，不代表本项目实测数据或真实解剖。

**讲述：**研究目标是检验共享编码和选择性路由能否共同解释压缩与恢复，而不是先假定所有神经元都重叠或所有阶段都由彼此隔离的模块完成。

## 7｜去抑制如何成为一种候选路由机制？

**本页要点：**控制回路可以许可内容通路通过，而不直接携带位置答案。

**机制示意：**

`(M_D/M_S) + 阶段时钟 → I_release ⊣ I_gate ⊣ E_target`

**配图：**将 E→E 内容通路与两级 I 回路并列画出：默认 `I_gate` 抑制目标通路；`I_release` 抑制 gate 后，源位置活动沿固定连线传递。控制信号只选择何时/哪路可通，不把正确位置直接写入目标神经元。

**讲述：**去抑制是一个可行的通路门控回路候选。相关综述提出这种 motif 能支持灵活通路控制；当前项目的模型也把这一回路具体化为可干预机制。但这两者都不能单独证明真实工作记忆中的 overlapping 神经元正由该回路因果性地路由至不同子空间。

## 8｜仓库目前已经实现并验证了什么？

**本页要点：**一个清晰边界的固定 E/I 原型，验证“给定规则后能否神经式地逐步解压缩”。

**屏幕文字：**固定连接、不训练｜四阶段在线读出｜`24/24` 无噪声完整序列

**补充数据：**`16/16` 自动化测试通过；39 项实验、936 个 trial 有轨迹归档与复算记录。

**配图：**优先使用仓库的真实 [验证轨迹图](../handcrafted_ei/artifacts/v1/validation.png)，显示响应活动、I_release/I_gate 与四次读出。不要用AI重画数据。

**讲述：**当前原型通过直接输入 `L/D/S`，在固定 E/I 动力学中测试保持、门控、分支继承和读出时序。它没有学会提取 primitive，没有实现压缩阶段，也没有拟合真实生理数据。它说明的是当前简化任务上的机制可行性。

## 9｜为什么大脑可能采用压缩？

**本页要点：**把两种机制放到“资源成本、记忆精度、项目干扰与泛化”之间比较，并提出可检验预测。

**屏幕文字：**压缩的收益：少用资源、复用结构｜压缩的代价：精度下降或干扰上升

**配图：**沿用[修订版机制比较海报](project_brief_assets_20261025/mechanism_candidates_compare_draft_v2.png)的资源几何与路由层次，补充可比较的指标，而不是把一个模型画成胜者：专属群体的成本/干扰基准；共享群体的泛化收益、误差与干扰；路由失灵时的阶段性错误。指标必须来自真实数据或未来模型评估，不预置结果。

**讲述：**这正对应申请书的“Why”目标：基于信息论、最优性与计算效率分析，问压缩在哪些条件下有利。当前可以提出收益—代价假说，不能说已证明大脑选择压缩是最优的。

## 10｜接下来如何把机制假说变成解释？

**本页要点：**从神经数据量化、机制模型比较，走向可证伪的干预与最优性分析。

**屏幕文字：**量化重叠与子空间 → 比较候选模型 → 干预路由机制 → 评估精度/成本权衡

**配图：**四步连续路线图。起点标注“已有：序列任务/神经数据与解压缩原型”；中间是两种模型比较；末端为“可区分的预测：路由改变是否造成特定子空间/阶段错误”。用淡灰表示待做，交大红仅标出当前已完成部分和关键检验。

**讲述：**具体优先级可先明确 overlap 与 subspace 的测量定义，检查它们与序列精度/干扰的关系，再比较专属子空间与重叠路由模型，最后设计能够区分二者的阶段特异干预。若要把当前v1拓展到压缩或数据拟合，需要独立规格与验收，不能暗中并入当前v1。
